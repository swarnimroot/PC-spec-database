Lineup — one laptop or several

Browse and Compare are merged into one page. It defaults to a single laptop (the roomy spec view), and grows side-by-side columns when you add more. Below: how each of the 5 pickers handles the morph from one → several. The spec content is identical across concepts — only the picker, and how you add a laptop, changes.

Proposed name: Lineup  (alternates: Showcase, Roster). Used throughout this mock.
